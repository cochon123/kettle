Kettle demo: wiring the Arduino

Your parts: Arduino UNO R4 Minima, mini breadboard, one 10 mm LED, four resistors, jumper wires and the big blue arcade button. The button becomes Margaret's physical "I'm fine" button, and it lights up: the LED goes inside the dome, so the button itself pulses during a check-in ("press me") and glows steadily when someone sends "thinking of you". There's no smart plug, so the kettle itself is simulated in software.

🔵 Big button → "I'm fine"Pressing it answers the check-in, so no neighbour gets asked.
💡 Light inside the buttonThe thing that asks is the thing you press. It pulses for "please press" and glows steadily for "thinking of you".
🔌 Arduino → laptop over USBThe UNO R4 Minima has no Wi-Fi, so it talks to the laptop over the USB cable (/dev/ttyACM0).
☕ Kettle → simulatedpython -m kettle demo --plug sim, then press K on the stage screen.

The diagram

Tip: ← / → arrow keys also work.

The board is drawn the usual way round, with USB on the left and the digital pins along the top edge. Yours is in its case and turned, so go by the pin labels printed on the board, not by position. On the breadboard, each column of 5 holes (a–e) is joined underneath, so anything in the same column is connected. The shaded columns 3, 7 and 8 are the ones used here.

Wire colours are only a suggestion. Any colour from your ribbon works. Using black for ground just makes mistakes easier to spot.

Step by step

  1. Unplug the USB cable first.

    Wire everything with the board off, then plug it back in at the end.

  2. Find out which resistors you have, then place one.

    Read the coloured bands. You want 330 Ω to 1 kΩ:

    330 Ω (orange-orange-brown): good   470 Ω (yellow-violet-brown): best   1 kΩ (brown-black-red): dimmer, fine

    220 Ω (red-red-brown): use two in series (column 3 → 5 and 5 → 7). 100 Ω (brown-black-brown): use all four in series (3 → 4 → 5 → 6 → 7).

    Bend the legs and push it into column 3, row b and column 7, row b. Resistors work either way round.

    Why not a smaller resistor: the UNO R4's pins are only rated for 8 mA, much less than the older UNO R3. With 330 Ω or more the LED stays under that limit.
  3. Put the light inside the button.

    Twist the lamp holder out from under the dome. It's the part with the brass tab. Then look inside it:

    It has a lamp (a small bulb or LED): slide a female jumper end onto each of its two tabs. This is often a 12 V lamp, so at 5 V it draws only a few mA and may glow dimly. If it stays dark, swap the two wires. That's harmless.

    It's empty: push your LED up into the dome through the holder's hole. Slide a female jumper end onto each leg, and remember which one is the long leg (+). The flat side of the rim is (−).

    Then plug the male ends into the breadboard: + → column 7, row a (same column as the resistor's right leg) and − → column 8, row a. A light put in backwards just stays dark. Flip it and nothing is damaged.

    Colour: a red LED behind the blue dome looks dim and muddy, because blue plastic blocks most red light. A white (or blue) LED makes the whole dome glow. Use the red one for now if that's all you have.
  4. Ground wire: Arduino GND → column 8.

    Use the GND pin on the top header, between AREF and 13. Push the other end into column 8, row e. The light's (−) wire and the button now share this ground.

  5. Signal wire: Arduino pin 9 → column 3.

    Pin ~9 (the ~ means PWM, which lets the light fade smoothly) goes to column 3, row e. That completes the light circuit: pin 9 → resistor → light in the button → GND.

  6. Make two button wires, find COM, and wire COM → column 8.

    The button's terminals are flat metal tabs, so a jumper pin can't plug into them. Cut one jumper wire in half. You get two wires, each with a pin on one end. Strip about 1 cm of insulation from each cut end. Push the bare copper through the hole in the tab (or wrap it tightly around the tab), twist it back on itself, and cover it with a bit of tape. Alligator clips or 4.8 mm / 2.8 mm spade connectors work too, if you have them.

    The white microswitch under the button has three silver terminals, with tiny letters moulded next to them: C (or COM), NO and NC. In your photo, "NO" is printed by the side terminals, and COM is probably the one pointing down. Trust the letters on your switch over the drawing. The brass tab with a hole higher up belongs to the lamp holder (step 2), not the switch.

    Attach the first wire to COM and push its pin into breadboard column 8, row d (ground).

  7. Wire NO → Arduino pin 2.

    Attach the second wire to NO and push its pin into the Arduino header at 2. Leave NC empty.

    The button needs no resistor. The Arduino's built-in pull-up holds pin 2 HIGH, and pressing the button connects it to ground (LOW). This wiring can't harm the board.
  8. Plug the USB back in and run the test sketch below.

    The button should breathe slowly. When you press it, the light turns fully on and the serial monitor prints PRESSED.

Test sketch

// Kettle demo, wiring test (UNO R4 Minima)
// Big button: COM -> GND, NO -> D2.  LED: D9 -> resistor -> LED(+), LED(-) -> GND.
const int BUTTON_PIN = 2;
const int LED_PIN = 9;          // PWM pin, so the light can breathe

bool wasPressed = false;

void setup() {
  Serial.begin(115200);
  pinMode(BUTTON_PIN, INPUT_PULLUP);   // internal pull-up: no resistor needed for the button
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  bool pressed = digitalRead(BUTTON_PIN) == LOW;   // pressed connects D2 to GND

  if (pressed) {
    analogWrite(LED_PIN, 255);                     // full brightness while held
  } else {
    float s = (sin(millis() / 350.0) + 1.0) / 2.0; // slow "please press" pulse
    analogWrite(LED_PIN, (int)(10 + 150 * s));
  }

  if (pressed != wasPressed) {
    Serial.println(pressed ? "PRESSED" : "released");
    wasPressed = pressed;
    delay(30);                                     // debounce
  }
}
Uploading it
  1. Arduino IDE 2 → Boards Manager → install "Arduino UNO R4 Boards".
  2. Board: Arduino UNO R4 Minima. Port: /dev/ttyACM0.
  3. Upload, then open the Serial Monitor at 115200 baud.

On this laptop, your user isn't in the dialout group yet, so uploading will fail with "permission denied". Run sudo usermod -aG dialout $USER once, then log out and back in.

If something's off
  • It prints PRESSED when you're not pressing: you're on NC. Move the blue wire to the other side terminal.
  • Nothing prints when you press: check the COM wire is in column 8 and the twisted ends are tight on the tabs.
  • Light dark: swap its two wires in columns 7 and 8. Check the yellow wire is on 9 and not on 8 or 10.
  • Light very dim: with a red LED behind the blue dome that's expected, so use a white LED. Otherwise check the resistor: 330–470 Ω is brighter than 1 kΩ or several in series.

How it plugs into Kettle

🔵 big button→ pin 2 → Arduino→ USB serial → small bridge script on the laptop→ edge hub POST /api/im_fine
edge hub GET /api/status→ check-in? glow? → bridge→ USB serial → Arduino→ pin 9 → 💡 the button pulses / glows

The test sketch above only checks the wiring. The demo firmware for the UNO R4, and the bridge script that connects it to the hub (it sends "pressed" and receives the light state), come next. They use the same two pins, so you won't need to rewire. The kettle stays simulated: start with --plug sim and press K on the stage screen at the "Margaret puts the kettle on" moment.
