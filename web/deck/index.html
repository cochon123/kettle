The insight

The power meter is the most honest wellbeing sensor in the house.

  • It already knows when someone got up, made tea, cooked, turned on the TV.
  • In Calgary it knows if the heat is on. Gas furnaces run an electric blower fan.
  • It's been done with a kettle since 2001. Zojirushi's i-Pot emails families in Japan. We need no special appliance, and the response is a neighbour, not a call centre.
